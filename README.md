﻿# Jogo dos Dados🎲🎲 

Neste jogo o jogador e o computador rolam um dado e avançam. O primeiro a chegar a linha de chegada vence! O jogo também inclui mecânicas de avanço, recuo e rodadas extras para deixar a partida mais emocionante.

Você também poderá escolher o nome do seu usuário no jogo, além de funções de avanço, recuo e rodadas extras para deixar a partida mais emocionante.

### Funcionalidades✅ 
- O jogador e o computador iniciam na posição 0.

- Cada um rola um dado (valores de 1 a 6) e avança esse número de casas.

- Se o jogador ou o computador tirar 6, ganha uma rodada extra.

- Se parar em uma casa especial, pode avançar ou recuar um determinado número de casas.

- O primeiro a atingir 30 casas vence o jogo.

- Mostra as posições finais no fim do jogo

- Opção de reiniciar o jogo após término

### Como rodar o código? 🤖

#### ❗❗Obs: Há a necessidade de ter o .NET SDK instalado em sua máquina previamente!

#### Passo a passo - Clone ou baixe o projeto  👞👞

1. Abra o terminal do seu editor de código;
2. Navegue até a pasta onde deseja instalar o projeto;
3. Clone o projeto 
ex:``` git clone git@github.com:alexandreSouza31/jogo-dos-dados-csharp.git```
 ou se preferir, baixe clicando no botão verde chamado "Code" no repositório desse projeto, e depois "Download zip.


#### Uso 💻
1. Inicie o App:
Certifique-se de estar na pasta do projeto, e navegue pelo terminal até o caminho do arquivo Program.cs
```
jogoDados.ConsoleApp\jogoDados.ConsoleApp>
```
2. Compile e execute o programa: ```dotnet run```

    ou, com o arquivo Program.cs aberto clique no botão verde(Current Document(Program.cs)) para iniciar

3. Siga as instruções no console e tente adivinhar o número!
